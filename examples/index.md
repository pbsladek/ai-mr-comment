# ai-mr-comment Examples

These examples are designed for day-to-day repository workflows. They are kept
outside `docs/index.md` so they do not change the GitHub Pages landing page.

Replace placeholder URLs, tokens, branch names, and model names with values from
your own repository.

## Example Files

- [local-review.md](local-review.md): review local and staged changes.
- [remote-pr-mr.md](remote-pr-mr.md): review GitHub PRs and GitLab MRs without a
  checkout.
- [remote-updates.md](remote-updates.md): update titles, descriptions, comments,
  labels, and reviewers.
- [quick-commit.md](quick-commit.md): generate and refine commits, including
  long messages, message templates, editor review, signoff, type/scope
  overrides, and staging control.
- [ci-and-docker.md](ci-and-docker.md): CI gating and container usage.
- [pipes-and-release-notes.md](pipes-and-release-notes.md): pipe integration,
  agent-friendly JSON, streams, and changelog output.
- [profiles.md](profiles.md): reusable local and CI profiles.
